# pgwarden

Governed Postgres access for AI assistants: an MCP gateway with OAuth 2.1 and OIDC login, one Postgres role per person, database-enforced read-only queries, PII masking, human-approved writes and a tamper-evident audit log. This repository is under active development; installation instructions, benchmarks and screenshots will land as the corresponding pieces ship.
